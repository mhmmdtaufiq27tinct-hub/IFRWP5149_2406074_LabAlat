# Kebutuhan tugas SIA P03

| ID | Kebutuhan |
|:--:|:--|
| SIA-R03 | Mahasiswa dapat mengajukan KRS. |
| SIA-R04 | Sistem memvalidasi KRS sebagai bagian pengajuan. |
| SIA-R05 | Mahasiswa dapat mengunduh bukti jika memilihnya pada konfirmasi pengajuan. |
| SIA-R06 | Dosen Wali dapat memproses persetujuan atau penolakan KRS. |

## Batas dan asumsi

- Pengguna terautentikasi; data mata kuliah, prasyarat, dan jadwal tersedia.
- Validasi gagal berarti pengajuan tidak tersimpan sebagai pengajuan berhasil.
- Unduh bukti bukan syarat keberhasilan; KRS tersimpan belum berarti disetujui.
- SIA-R01 dan SIA-R02 serta Admin Akademik berasal dari P02 dan tidak disalin ke diagram tugas SIA P03.
- Pembayaran, pengisian nilai, dan rancangan basis data berada di luar cakupan.
