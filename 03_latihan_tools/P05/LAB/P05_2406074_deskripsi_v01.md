# Skenario use case LAB P05

## LAB-UC03 Ajukan Peminjaman

| Elemen | Deskripsi |
|:--|:--|
| Tujuan | Menyimpan permohonan peminjaman yang memenuhi syarat |
| Aktor | Peminjam (Mahasiswa atau Dosen) |
| Sumber kebutuhan | LAB-R03, LAB-R04 |
| Pemicu | Peminjam memilih Ajukan Peminjaman |
| Prasyarat | Pengguna terautentikasi; data peralatan tersedia |
| Pascakondisi berhasil | Pengajuan tersimpan dengan status Menunggu keputusan dan nomor pengajuan |
| Pascakondisi gagal | Tidak ada pengajuan baru yang berhasil tersimpan |
| Include | LAB-UC04 Periksa Ketersediaan; selalu dilakukan sebelum penyimpanan |
| Extension point | Bukti pengajuan tersedia setelah pengajuan tersimpan |
| Extend | LAB-UC05 Cetak Bukti Pengajuan jika [mahasiswa memilih cetak] |

### Alur utama

| Langkah | Kegiatan aktor | Respons sistem |
|:--:|:--|:--|
| 1 | Memilih peralatan, jumlah, dan rentang waktu | Menampilkan form pengajuan |
| 2 | Mengisi dan mengirim pengajuan | Memeriksa kelengkapan data |
| 3 | — | Memeriksa ketersediaan peralatan (LAB-UC04) |
| 4 | — | Menyimpan pengajuan berstatus Menunggu keputusan dan membuat nomor |
| 5 | Melihat konfirmasi | Menampilkan ringkasan dan menyediakan bukti |
| 6 | Memilih cetak, bila diinginkan | Menjalankan LAB-UC05 hanya bila kondisi extend terpenuhi |

### Alur alternatif

- A1 pada langkah 2: data tidak lengkap; sistem menunjukkan bagian yang perlu diperbaiki dan tidak menyimpan pengajuan.
- A2 pada langkah 3: peralatan/jumlah tidak tersedia; sistem menyampaikan ketidaktersediaan dan tidak menyimpan pengajuan berhasil.
- A3 pada langkah 5: mahasiswa tidak memilih cetak; pengajuan tetap berhasil.

## LAB-UC11 Catat Pengembalian Peralatan

Petugas memilih peminjaman yang akan dikembalikan. Sistem hanya mengizinkan pencatatan jika status Dipinjam dan jumlah sesuai. Petugas mengonfirmasi alat kembali dan memeriksa kondisinya melalui LAB-UC12 (Baik, Rusak Ringan, atau Rusak Berat). Sistem mencatat tanggal dan kondisi, lalu mengubah status menjadi Selesai. Jika status/jumlah tidak sesuai, pencatatan ditolak tanpa perubahan. Kerusakan tidak otomatis menghasilkan denda.
