# Logbook Pertemuan 3

## Checklist LAB dan SIA

- [x] Aktor memiliki interaksi yang jelas.
- [x] Use case sesuai kebutuhan dan berada dalam batas sistem.
- [x] Include menunjuk perilaku yang selalu disertakan.
- [x] Extend menunjuk use case dasar dan memiliki kondisi serta extension point.
- [x] Pengajuan tetap berhasil tanpa perilaku tambahan yang bersyarat.
- [x] Prasyarat dibedakan dari perilaku include.
- [x] Alur alternatif menjelaskan kegagalan dan hasilnya.
- [x] Diagram dan deskripsi menggunakan ID yang sama.
- [x] Kebutuhan belum dimodelkan dicatat sebagai batas, bukan diasumsikan selesai.

## Catatan

Periksa ketersediaan LAB dan validasi KRS SIA adalah perilaku wajib dalam pengajuan masing-masing. Cetak/unduh bukti hanya berjalan bila dipilih setelah pengajuan tersimpan.
